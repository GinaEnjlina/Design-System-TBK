Aturan pakai
  • Ruang bersih minimal setinggi logomark di semua sisi — jangan ditempel elemen lain.
  • Ukuran minimum: 20px tinggi untuk logomark, 24px untuk logotype — di bawah itu tidak terbaca.
  • Jangan diregangkan, dirotasi, atau diberi warna selain Classic Blue asli.
  • Logomark untuk favicon, avatar, dan ruang sempit; logotype untuk header dan dokumen resmi.
Sesuai aturan tata kelola aset (brief §2), file mentah (SVG/AI/EPS) cukup ditautkan dari repo aset brand, bukan digandakan ke setiap proyek yang memakainya.
Filosofi
Logo TBK adalah simbol identitas perusahaan yang modern, dinamis, dan siap menghadapi tantangan transportasi masa depan. Bentuk tipografi "t-b-k" yang sederhana namun kokoh dipadukan dengan siluet burung yang melambangkan kebebasan dan visi luas — merepresentasikan perjalanan tanpa batas: darat, laut, maupun udara.
Tipografi — dibuat modern, sederhana, dan mudah dikenali.
Starting point — menjaga keseimbangan visual agar logo terasa stabil dan harmonis.
Burung — simbol visi luas, kebebasan, kecepatan, serta jangkauan darat, laut, dan udara.
Anatomi bentuk
tipografi "t-b-k"
Starting Point — kotak keseimbangan
Siluet Burung — lengkung atas
Setiap bagian logomark punya peran: dua kotak menjaga keseimbangan visual sebagai starting point, lengkung bawah membentuk huruf "t-b-k", dan lengkung atas membentuk siluet burung yang melambangkan visi dan kebebasan.
Varian warna
Putih — untuk latar gelap/foto
Hitam — untuk cetak satu warna
Warna asli Classic Blue tetap default. Putih/hitam hanya untuk kondisi latar yang membuat versi berwarna tidak cukup kontras.
Pattern dekoratif
Motif grid halus dari brand guideline — hanya untuk latar materi pemasaran, tidak pernah dipakai di komponen produk.

  • Navigasi seluruh alur hanya dengan keyboard (Tab, Enter, Esc, arrow) — tidak ada jebakan fokus di luar modal.
  • Uji dengan screen reader (VoiceOver/NVDA): judul modal, status alert, dan label ikon terbaca.
  • Perbesar browser ke 200% — layout tidak rusak, teks tidak terpotong.
  • Cek kontras dengan alat seperti axe atau Lighthouse — target AA di semua teks.
  • Aktifkan prefers-reduced-motion di OS — transisi berhenti/berkurang.
  • Seluruh UI dari components/ui/ shadcn — tidak ada komponen buatan sendiri di luar itu.
  • Styling hanya lewat Tailwind. Tidak ada inline CSS, kecuali passthrough CSS variable.
  • Warna hanya lewat token semantik (--primary, --destructive, dst) — tidak pernah hex langsung atau --tbk-500 untuk teks.
  • Semua modal memakai Dialog; konfirmasi destruktif wajib AlertDialog, tidak pernah Dialog biasa.
  • Semua formulir memakai Form + Input/Select + Label lewat FormField, divalidasi dengan react-hook-form + zod.
  • Satu tombol primary per area layar.
  • Preview komponen di situs ini dirender dari komponen produksi yang sama — bukan salinan terpisah.
Perubahan nilai token semantik dan penghapusan varian dihitung breaking change dan wajib masuk Changelog.
  • Kalimat deklaratif pendek. Istilah teknis (variant, props, token) dibiarkan dalam bahasa Inggris karena itu yang muncul di kode.
  • Label memakai kata benda/kerja polos: "Simpan", "Batal", "Nama", "Pelanggan" — bukan sinonim yang dibuat-buat.
  • Tidak ada tanda seru, tidak ada nada pemasaran.
  • Empty state: satu judul, satu kalimat instruksi — bukan copy lucu.
  • Pesan error langsung menyebut masalahnya.
